# LimonrstX’s Spotify Client

Minecraft **1.21.11** için Fabric müzik modu.

**[En son sürümü indir](https://github.com/LimonrstXMC/limonrstx-spotify-releases/releases/latest)**

Spotify ve SoundCloud widget’ları, isim üstü şarkı kartları, albüm kapakları, söz widget’ı, Sky Lyrics, temalar ve VIP özellikleri.

## Kurulum
Java 21+, Fabric Loader 0.18.2+, Fabric API 0.141.1+ ve Mod Menu 17.0.0+ gerekir. JAR’ı `mods` klasörüne koy; eski spotifyhud JAR’ını kaldır. **Config’i silme.** VDS güncellemesi gerekmez.

`O`: Oynatıcı · `Ş`: Ayarlar. Tuşlar Minecraft kontrollerinden değiştirilebilir.

Masaüstü müzik ve oyun içi SoundCloud Windows gerektirir. Sky Lyrics, Spotify hesap bağlantısı ve özel fotoğraf arka planı aktif VIP gerektirir. Spotify bağlantısı ayrıca Spotify’ın uygulama erişim koşullarına tabidir.

## Güncellemeler
1.0.8’den itibaren mod açılışta yeni sürümü kontrol eder. Ayarlar → Güncellemeler → İndir üzerinden hazırlanır; Windows’ta oyun kapatılınca kurulur. Otomatik kontrol kapatılabilir. İndirme boyutu, SHA-256, mod kimliği ve Minecraft sürümü doğrulanır. Mevcut mod dosyası yedeklenir; kişisel ayarlar ve hesap dosyaları korunur.

## Veri kullanımı
Şarkı paylaşımı açıksa oyuncu kimliği ve parça bilgileri müzik servisine gönderilir. VIP servisi Minecraft oturumunu doğrular. Kapaklar Spotify/SoundCloud görsel sunucularından indirilebilir. Güncelleme kontrolü GitHub API’sine bağlanır. Normal tarayıcı çerezleri içe aktarılmaz; Spotify ve SoundCloud hesap bilgileri bu depoda yer almaz.

Bu depo yalnızca hazır sürümler ve sürüm notları içindir. Kaynak kod deposu özeldir. Spotify, SoundCloud, Microsoft veya Mojang ile resmi bağlantı yoktur.
